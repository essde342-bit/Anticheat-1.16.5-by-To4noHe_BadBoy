# Телефон / GitHub

1. Открой репозиторий на GitHub.
2. Замени старые файлы содержимым из этого архива.
3. Создай/обнови все пути точно как в архиве.
4. Открой Actions.
5. Запусти Build EssGuard.
6. После успешной сборки скачай artifact `EssGuard-1.16.5`.
7. Положи `EssGuard-1.16.5.jar` в `plugins/` своего Paper 1.16.5.
8. Перезапусти сервер.
9. Для проверки алертов выдай себе OP или permission `essguard.alerts`.
10. Для тестового аккаунта, которому не нужно проверяться, используй `essguard.bypass`.
